# Website Creator - Version 2.0 Plan

## Current Status (v1.0)
✅ Light "Relax Mind" Theme
✅ App Shell (Sidebar, Header, Layout)
✅ Dashboard with Project Cards
✅ Builder with Drag & Drop Components
✅ Basic Component Rendering (Text, Button, Image, Container)

## Version 2.0 Features

### 1. Component Editing & Properties
- **Inline Editing**: Double-click text/button to edit content
- **Properties Panel**: Right sidebar for component styling
  - Text: Font size, color, alignment
  - Button: Background color, border radius, padding
  - Image: Width, height, border radius
  - Container: Background, padding, flex direction

### 2. Component Management
- **Delete Components**: Click X button on hover
- **Reorder Components**: Drag to reorder within canvas
- **Undo/Redo**: History management for actions

### 3. Project Persistence
- **Save Project**: Save current page state to localStorage
- **Load Project**: Load saved projects from dashboard
- **Export HTML**: Generate clean HTML/CSS code

### 4. Enhanced Builder UI
- **Layers Panel**: Show component hierarchy
- **Zoom Controls**: Zoom in/out on canvas
- **Responsive Preview**: Switch between Desktop/Tablet/Mobile views

### 5. Additional Components
- **Heading** (H1, H2, H3)
- **Paragraph**
- **Link**
- **Divider**
- **Card** (pre-styled container)

### 6. Template System
- **Pre-built Templates**: Landing page, Portfolio, Blog
- **Template Preview**: Visual template selection
- **Apply Template**: Start from template

## Implementation Priority
